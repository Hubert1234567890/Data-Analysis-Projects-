# Data Analysis Projects

A collection of data analysis projects using Python, Pandas, NumPy, and data visualization.

## Projects

### 1. Project DOR — Business Performance Analysis

Analysis of Project DOR's business performance for October and November 2025.

#### Analysis Includes
- Data cleaning and preprocessing
- Production analysis
- Retail and stall sales analysis
- Revenue calculation
- COGS calculation
- Gross Profit and Gross Profit Margin
- Operating Expenses
- Net Profit and Net Profit Margin
- Retail vs Stall profitability analysis
- Product contribution margin analysis
- Business performance visualization
- Data-driven recommendations

#### Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab
